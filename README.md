## 📖 معرفی پروژه (Overview)

**ربات پدرخوانده (Godfather Bot)** یک بازی چندنفره آنلاین متنی، اقتصادی، استراتژیک و نقش‌آفرینی (RPG) بر بستر پلتفرم تلگرام است. این ربات با بهره‌گیری از فریمورک قدرتمند **Aiogram 3** به صورت کاملاً غیرهمگام (Asynchronous) پیاده‌سازی شده و از پترن‌های معماری ماژولار و دیتابیس اورکستریشن با **SQLAlchemy 2.0 Async** بهره می‌برد.

این پروژه علاوه بر قابلیت اجرا در محیط محلی (Polling) یا سرورهای اختصاصی (VPS)، با معماری **Passenger WSGI** بهینه‌سازی شده تا بتواند روی هاست‌های اشتراکی cPanel با کمترین منابع و حداکثر پایداری اجرا شود.

## 🌟 سیستم‌ها و قابلیت‌های اصلی بازی (Core Modules)

### 🏙️ ۱. مدیریت شهر و املاک (City & Real Estate)
* **شهرداری و مدیریت شهری:** تصاحب شهرداری، تنظیم مالیات‌ها، تعیین سیاست‌های رفاهی و امنیتی شهر.
* **خرید و فروش املاک:** انبارها، پایگاه‌های مخفی، کارخانه‌ها و عمارت‌های تجملی با سودآوری روزانه.
* **سیستم انبارداری:** ذخیره‌سازی غنائم، تسلیحات و منابع با ظرفیت قابل ارتقا.

### 🧪 ۲. دنیای تاریک (Dark World System — v1.8.4.6)
* **آزمایشگاه و ۱۲۵ فرمول سری:** تولید و سنتز محصولات صنعتی و مخفی.
* **سیستم استخدام و تیم‌سازی:** بکارگیری تکنسین‌ها، قاچاقچیان و نیروهای ویژه.
* **مکانیک Heat & Trace:** مدیریت ریسک شناسایی پلیس و بازرسی‌ها.
* **ناوبری شیشه‌ای و راهنمای تعاملی:** راهنمای ۹ صفحه‌ای آموزشی همراه با دکمه‌های ناوبری سریع.

### ⚔️ ۳. جنگ‌ها و ارتش مافیایی (Military & Alliances)
* **نیروهای نظامی:** سربازان پیاده، تک‌تیراندازها، تانک‌ها، هلیکوپترها و سیستم‌های ضدجاسوسی.
* **اتحادیه‌ها (Alliances):** ایجاد و پیوستن به فمیلی‌های قدرتمند، اعلام جنگ، صلح و تصاحب شهرهای رقیب.
* **ماموریت‌های جاسوسی:** نفوذ به تشکیلات دشمن، استخراج اطلاعات حساب‌ها و خرابکاری در صنایع حریف.

### 🏦 ۴. اقتصاد و بانک جهانی (World Bank & Economy)
* **بانکداری پیشرفته:** حساب‌های سپرده سرمایه‌گذاری با سود روزانه، اخذ وام، ضمانت‌نامه‌ها و صندوق امانات.
* **بازار سیاه و حواله‌ها:** سیستم انتقال پول بین بازیکنان با کارمزد پویا و ردیابی مالی.

### ⚽ ۵. ورزش و سرگرمی (Sports & Football)
* **لیگ فوتبال اختصاصی:** مسابقات هفتگی، جام‌های قهرمانی و لیگ جمعه‌ها.
* **بازار نقل و انتقالات:** خرید و فروش بازیکنان فوتبال، استعدادیابی و شرط‌بندی ورزشی.

### 👑 ۶. عناوین و افتخارات (Prestige & Titles System)
* **سیستم دستاوردها:** بیش از ده‌ها عنوان منحصربه‌فرد، اسطوره‌ای و دسته‌ای بر اساس عملکرد، ثروت و نبردهای بازیکن.

## 🗂️ ساختار ریپازیتوری (Repository Architecture)

```text
Godfathers/
├── app/                                       # سورس کد کامل برنامه
│   ├── database/                              # مدیریت ارتباط دیتابیس (SQLAlchemy Engine & Sessions)
│   ├── handlers/                              # کنترلرها و هندلرهای رویدادها و دستورات تلگرام
│   ├── keyboards/                             # کیبوردهای اینلاین و شیشه‌ای (Menus & Navigation)
│   ├── middlewares/                           # میدل‌ورهای احراز هویت، ثبت لاگ و پریمیوم ایموجی
│   ├── models/                                # مدل‌های پایگاه‌داده (Database Entities)
│   ├── services/                              # لایه بیزینس‌لاجیک، پردازش مالی، جنگ‌ها و تیکرها
│   ├── utils/                                 # ماژول‌های کمکی، فرمت‌بندی تاریخ و ایموجی‌ها
│   └── data/                                  # داده‌های ثابت بازی، تعاریف کارخانه‌ها و عناوین
├── docs/                                      # اسناد، مشخصات فنی و منابع راهنما
│   ├── DARK_WORLD_USER_HIRING_SPEC.md         # مشخصات سیستم استخدام دنیای تاریک
│   ├── FICTIONAL_PRODUCTS_AND_FORMULAS_FA.pdf # مستند فرمول‌ها و محصولات
│   ├── HOTFIX_1.8.4.6.md                      # گزارش تغییرات نسخه نهایی
│   └── titles_system_stage11.xlsx             # جدول داده‌های سیستم القاب
├── tools/                                     # ابزارهای تولید داده و اسکریپت‌های بیلد
│   └── build_titles.py                        # اسکریپت تولید ساختار القاب
├── bot.py                                     # اسکریپت اجرای ربات در حالت Polling (توسعه و VPS)
├── passenger_wsgi.py                          # نقطه ورود اجرایی برای هاست‌های اشتراکی cPanel
├── cron_ticks.py                              # موتور پردازش تیک‌های زمان‌بندی‌شده و روتین‌ها
├── requirements.txt                           # وابستگی‌ها و کتابخانه‌های پایتون
├── VERSION.txt                                # برچسب نسخه نرم‌افزار
├── .gitignore                                 # قوانین نادیده‌گرفتن فایل‌های حساس
└── .env.example                               # قالب متغیرهای محیطی مورد نیاز
```

## 🚀 راهنمای نصب و راه‌اندازی (Quick Start)

### ۱. پیش‌نیازها
* **Python 3.11** یا بالاتر
* دیتابیس **SQLite** (پیش‌فرض) یا **PostgreSQL**

### ۲. کلون کردن ریپازیتوری
```bash
git clone https://github.com/Mr-VioletX/Godfathers.git
cd Godfathers
```

### ۳. ساخت محیط مجازی و نصب وابستگی‌ها
```bash
# ایجاد محیط مجازی
python -m venv .venv

# فعال‌سازی در ویندوز:
.venv\Scripts\activate
# یا در لینوکس / مک:
source .venv/bin/activate

# نصب کتابخانه‌ها
pip install -r requirements.txt
```

### ۴. تنظیم متغیرهای محیطی
یک کپی از فایل `.env.example` با نام `.env` ایجاد کرده و مقادیر لازم را پر کنید:
```bash
cp .env.example .env
```

فایل `.env`:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ_example
DATABASE_URL=sqlite+aiosqlite:///godfather.db
ADMIN_IDS=123456789,987654321
CREATOR_ID=123456789
ADMIN_PASSWORD=your_strong_admin_password
ARCHIVE_CHANNEL_ID=-1001234567890
NEWS_CHANNEL_ID=-1001234567890
```

### ۵. اجرای پروژه
* **اجرای محلی یا روی VPS:**
  ```bash
  python bot.py
  ```
* **اجرای روی هاست اشتراکی (cPanel):**
  کافیست در بخش **Setup Python App** در cPanel، فایل اسکریپت ورودی را `passenger_wsgi.py` انتخاب کنید.
* **تنظیم کران‌جاب‌های دوره‌ای (Cron Job):**
  برای محاسبه سود بانکی، آپدیت‌های شهری و تیک‌های پس‌زمینه، اسکریپت زیر را در Cron Job هاست تنظیم کنید:
  ```bash
  * * * * * cd /path/to/Godfathers && /path/to/.venv/bin/python cron_ticks.py > /dev/null 2>&1
  ```

## 🛡️ امنیت و حریم خصوصی (Security)

* هیچ‌گونه توکن، رمز عبور، آدرس دیتابیس فعال یا داده‌های شخصی کاربران در این ریپازیتوری ذخیره نشده است.
* فایل `.gitignore` پروژه به شکلی پیکربندی شده که از آپلود تصادفی فایل‌های دیتابیس (`*.db`)، فایل‌های محرمانه (`.env`) و لاگ‌ها ممانعت به عمل می‌آورد.
