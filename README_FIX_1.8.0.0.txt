مرحله ۸۰ — v1.8.0.0
====================

۱) تاگل برگشتِ جداگانه برای هر بخش
----------------------------------
ادمین‌مود ← ابزارها ← «📊 فرمت جدول» حالا یک **منو** است:
• یک Master (روشن/خاموش همه)
• هر بخش جداگانه روشن/خاموش می‌شود و به حالت اول برمی‌گردد:
  رنکینگ اصلی / رنکینگ کاپ اتحادیه / سربازخانه+صف ساخت اتحادیه / جدول لیگ+گروه فوتبال /
  اسکادر فوتبال / نیروها+صف نظامی / شهر / انبار / بازار / برند
• خاموش کردن یک بخش ← فقط همان بخش به حالت اول (متن ساده) برمی‌گردد؛ بقیه جدول می‌مانند

۲) جدول‌بندی بخش‌های بیشتر (monospace <pre>)
--------------------------------------------
علاوه بر قبلی‌ها، حالا این‌ها هم جدول‌بندی شدن (با همان تاگل جداگانه):
• 📦 انبار اصلی (موجودی محصولات)
• 🏙️ بخش شهر (دارایی‌ها + صف ساخت/در حال ساخت)
• 🎖️ نیروها و صف پرورش نظامی
• سربازخانهٔ اتحادیه + صف تولید (از قبل)

۳) سرعت رشد جمعیت شهر (درخواست دقیق)
------------------------------------
• رضایت ۱۰۰٪ ← کل ظرفیت خالی خانه‌ها در یک سال پر می‌شود
• رضایت ۷۵٪ (حداقل رشد) ← ۲۵٪ ظرفیت در هر سال پر می‌شود
• بین ۷۵ تا ۱۰۰ به‌صورت خطی مقیاس می‌شود
• تابع grow_population + annual_growth_rate بازنویسی و تست شد

فنی: table_mode_on(section) + رجیستری TABLE_SECTIONS + منوی ادمین — کامپایل سالم، تست رشد پاس
