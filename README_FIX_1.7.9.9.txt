رفع‌ها و قابلیت‌های نسخه‌ی 1.7.9.9
==================================

لیگ جمعهٔ رسمی فوتبال (F4)
---------------------------
🏆 ساختار (تأیید امیر): دوری **رفت‌وبرگشت** — هر تیم با هر تیم ۲ بار بازی می‌کند (۴ تا ۲۴ تیم)
📅 زمان‌بندی: ثبت‌نام تا **پنجشنبه**؛ بازی‌ها **جمعه** به‌صورت خودکار شبیه‌سازی می‌شوند
🎁 جایزهٔ قهرمان/نایب‌قهرمان: **دلار بازی + XP سرمربی + طرفدار**

• «🗓️ لیگ جمعه (رسمی)» در منوی فوتبال: ثبت‌نام + وضعیت من + جدول لیگ (با جدول monospace)
• زمان‌بند: هر ۵ دقیقه (و در cron) چک می‌کند — اگر جمعه باشد و لیگ برگزار نشده، فیکسچر تولید و همهٔ بازی‌ها شبیه‌سازی و جوایز داده می‌شود
• جدول فصل مرتب (امتیاز ← تفاضل ← گل‌زده) + به‌روزرسانی جدول دائمی و رنکینگ ورزش
• سیدبندی ۳ سبدی + تولید فیکسچر دایره‌ای (هر تیم با بقیه رفت‌وبرگشت)

فنی:
• جدول‌های تازه: football_league_seasons / entries / fixtures (بدون مهاجرت)
• سرویس تازه: services/football_friday.py (ثبت‌نام + فیکسچر + شبیه‌سازی Poisson + جوایز + زمان‌بند)
• ویرایش: engine، football_menu، football.py (fb:friday)، cron_ticks + bot.py (زمان‌بند جمعه)
• تست: ساختار round-robin + امتیاز ۳/۱/۰ — کامپایل سالم
