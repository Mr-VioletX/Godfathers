==========================================================
  GODFATHERS BOT — مرحله ۲۷.۱ (به‌روزرسانیِ راهنماها + XP باقی‌مانده + بهینه‌سازیِ سرعت)
==========================================================

این بسته دقیقاً همان کدِ مرحله ۲۷ است + چهار تغییرِ تازه:

۱) پروفایل — مقدارِ XP باقی‌مانده
   - app/data/leveling.py : توابعِ تازه
       xp_remaining(player)  → چند XP تا سطحِ بعد مانده
       progress_bar(player)  → نوارِ ██████░░░░
       progress_line(player) → خطِ کاملِ «XP: 250 / 500 ██████░░░░» + «باقی‌مانده تا سطحِ N: 250 XP»
   - app/handlers/profile.py : کارتِ پروفایل حالا سطح + نوارِ XP + XP باقی‌مانده را نشان می‌دهد.
   - در سقفِ سطح (۵۰) به‌جای عدد، «MAX» نمایش داده می‌شود.

۲) دستیار (کنسیلیری) — به‌روزرسانیِ کامل
   - app/handlers/assistant.py :
       * گزارشِ خصوصی و گزارشِ عمومی هر دو نوارِ XP و XP باقی‌مانده را نشان می‌دهند (_xp_line).
       * در «راهنمای سطحِ تو» یک خطِ تازه اضافه شد: چند XP تا سطحِ بعد مانده + یادآوریِ اینکه
         ساخت‌وساز/ارتقا/استخدام/تولید/فروش/ارتش/ورزش همه XP می‌دهند.
   - app/data/assistant.py (PROGRESSION) : تسک‌های هر درجه با امکاناتِ مرحله ۲۷ به‌روز شد:
       ۴۰ حرفه‌ای، دکمه‌های دسته‌جمعیِ عمارت، کاهشِ زمانِ دزدیِ کاپولا (تا ۲۰ لِوِل)،
       سهمِ خودکارِ انبار (تا ۵۰٪)، دکمه‌های دسته‌جمعیِ کارخانه، ورزش تا لولِ ۵۰.

۳) واکترو و راهنماها
   - app/data/walkthrough.py :
       * فاز کاربر: بخشِ «رازِ سرعتِ رشد» (همه‌چیز XP می‌دهد + XP باقی‌مانده در پروفایل).
       * واکترو کامل: «فصل ۱۱ — هرمِ پایگاه و عمارت» (مسیر مخفیگاه → خانه‌ی امن → مرکزِ فرماندهی →
         پایگاهِ تیرِ ۴ با نام‌های Palazzo/Bastione/Mercato/Velo/Dogana/Tesoro/Clinica/Caserma/Officina/Curia
         → عمارتِ مربوطه، ۱۰ بار تکرار تا اتمامِ هرم) و «فصل ۱۲ — تجربه و اونت‌ها».
       * راهنمای دستورات: بخشِ «🆕 تازه‌هایِ این نسخه» با ۹ موردِ مرحله ۲۷ و توضیحِ انبار.

۴) بهینه‌سازیِ سرعت (رفعِ کندیِ گزارش‌شده)
   - app/database/engine.py :
       * SQLite PRAGMA ها روی هر کانکشن: journal_mode=WAL، synchronous=NORMAL،
         temp_store=MEMORY، cache_size=~16MB، busy_timeout=30000
         → پایانِ قفل‌شدن‌ها و تأخیرهایِ نوشتن؛ خواندن و نوشتن هم‌زمان.
       * pool_pre_ping=True؛ و برای دیتابیس‌های غیرِ SQLite: pool_size=10، max_overflow=20، pool_recycle=1800.
   - app/middlewares/tracking.py :
       * مسیرِ سریع (fast path) برای هر پیامِ خصوصی: اول بررسیِ ارزان (تنظیمِ اعلام + کول‌داون)،
         بعد فقط یک commit برای last_seen/username. قبلاً تا ۳ بار commit و یک کوئریِ اضافیِ القاب
         روی هر پیام اجرا می‌شد.
       * کوئریِ «لقبِ فعال» فقط وقتی اجرا می‌شود که واقعاً قرار است اعلامِ آنلاین ارسال شود.

----------------------------------------------------------
نصب (هاست / cPanel)
----------------------------------------------------------
۱) فایل‌های داخلِ زیپ را در /home/godfathe/godfather_bot/ کپی/جایگزین کنید (روی نسخه‌ی مرحله ۲۷).
۲) .env دست‌نخورده بماند.
۳) از Setup Python App → Restart استفاده کنید.
۴) نسخه‌ی hosting شاملِ passenger_wsgi.py است؛ نسخه‌ی normal بدونِ آن (اجرا با: python bot.py).

تستِ سریع پس از روشن‌کردن:
  • «پروفایل» → باید نوارِ XP و «باقی‌مانده تا سطحِ بعد» دیده شود.
  • «واکترو» → فصل‌های ۱۱ و ۱۲ و بخشِ «تازه‌هایِ این نسخه».
  • «دستیار» → گزارش، باید خطِ XP داشته باشد.
  • چند پیامِ پشت‌سرهم در چتِ خصوصی → پاسخ‌ها باید بدونِ تأخیر باشند (WAL + fast path).
